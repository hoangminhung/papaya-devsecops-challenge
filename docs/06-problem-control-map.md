## How to read this

One row per problem from the framing. **Controls** name the framework layer (L1–L8; "risk-level L3" means the change level of layer 3), ADR or threat
(T*n*, [`05-threat-model.md`](05-threat-model.md)) that answers it. **Evidence** is what shows the control
works. Codes: S*n* success criteria and GĐ-*n* assumptions of the framing, G*n* framework gaps,
OD*n* owner decisions, D1–D3 owner decisions in research 6.6, "Options §n" sections of
`work/03-options.md`. **Coverage**:

- **Covered:** the core of the problem is closed by a control enforced outside the agent (IAM,
  GitHub, CI). What stays open is listed as **Residual**; a date (end of phase 1, phase 2) says when
  the control is in place.
- **Partial:** the control is process only, or the core of the problem is still open. Laptop-side
  settings count as process, since they can be skipped without MDM (ADR-0007).
- **Gap:** the core of the problem has no control in this framework; partial mitigations may be
  listed, and the open part is marked **none** with the reason.
- **Out of scope:** excluded by the framing (§1.4).

Markers follow the framework legend (📖, ⚠️, [design]). `[map finding, not in framework gaps]` marks an
open point this map found that the framework's gap list (G1–G20) does not yet contain; claims about tools are cited in the framework
and ADRs, so this table points there rather than repeating citations.

## Summary

- **Covered (10):** P1b, P2a, P2b, P3a, P5a, P5c, P6b, P9b, A2, A8. IAM, the merge gate, the
  `production` environment or OIDC close the core; each row lists its
  residual, and most hold only from the end of phase 1 or from phase 2.
- **Partial (27):** P1a, P1c, P2c, P3b, P3c, P4a–c, P5b, P5d, P6a, P7a, P7b, P8a, P8b, P9a, A1, A3–A6,
  A7b, A9, A10, A11, A12a, A13. The control is process (laptop settings included), or the core is still
  open.
- **Gap (2):** P9c (review quality of large agent PRs), A12b (data residency per country).
- **Out of scope (1):** A7a (production AI agents).

Three causes explain most Partial rows: controls on the laptop are process or can be skipped without
MDM (G11); k0s, GCP and Firebase mechanisms are open (G1–G3); and several controls have no designed
mechanism yet (the `[map finding]` cells).
